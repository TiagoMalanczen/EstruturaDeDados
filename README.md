#  Estudos de Estrutura de Dados e Algoritmos em C

Repositório dedicado ao estudo prático de estruturas de dados fundamentais, manipulação de memória de baixo nível e análise de eficiência assintótica em linguagem C. 

---

##  Objetivo
Dominar os conceitos de baixo nível da computação: endereçamento, gerenciamento explícito de memória na Heap/Stack, construção de Tipos Abstratos de Dados (TADs) e análise da complexidade de algoritmos.

---

##  Tópicos Abordados

- **Gerenciamento de Memória:** Operadores de endereço e desreferenciação (`&`, `*`), aritmética de ponteiros, alocação e desalocação dinâmica manual (`malloc`, `calloc`, `realloc`, `free`).
- **Análise Assintótica:** Avaliação de complexidade temporal e espacial com notação Big O.
- **Recursão:** Condições de parada, pilha de chamadas (*call stack*) e resolução recursiva de problemas.
- **Algoritmos de Busca:** Busca linear, busca binária e critérios de eficiência em vetores ordenados.
- **Tipos Abstratos de Dados (TADs):** Separação estrita entre interface (`.h`) e implementação (`.c`).
- **Estruturas Lineares:** Listas dinâmicas, pilhas (*stacks*) e filas (*queues*).
