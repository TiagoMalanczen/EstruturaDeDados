# 🏗️ Estrutura de Dados (C / UTFPR)

Repositório dedicado ao estudo de algoritmos, organização de dados em memória e eficiência computacional, seguindo a ementa da disciplina na UTFPR.

## 📂 Organização do Conteúdo
- **AlgoritmosBusca:** Implementação de busca sequencial, binária e outras estratégias de localização.
- **FundamentosMemoria:** Estudos sobre ponteiros, alocação dinâmica e endereçamento.
- **Recursividade:** Resolução de problemas complexos através de chamadas recursivas e análise de empilhamento.

## 🧠 Tópicos Estudados
- **Gestão de Memória:** Uso de `malloc`, `free` e manipulação direta via ponteiros.
- **Análise de Algoritmos:** Complexidade de tempo e espaço (Notação Big O).
- **Tipos Abstratos de Dados (TADs):** Modularização e encapsulamento de estruturas.
- **Estruturas Lineares:** Listas encadeadas, pilhas e filas.

## 🛠️ Ferramentas
- **Linguagem:** C (Padrão ANSI/C99).
- **Compilador:** GCC.
- **Ambiente:** Terminal / VS Code.
